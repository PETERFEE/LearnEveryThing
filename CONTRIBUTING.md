# Contributing

Thanks for helping keep this learning skill accurate and useful.

## Submitting a new resource

Propose an issue or pull request containing: title, canonical URL, author/provider, domain, tier, exact technical topics, expected prerequisites, format, why it suits a **specified learner profile**, pricing/access if current, and dated primary-source verification. For a community verdict, link to specific practitioner discussion(s). Do not claim consensus from one anecdote or star ratings.

## Updating existing entries

Include a before/after change, changed course or SDK version, date verified, and reference link. A working resource can be Tier 4 for new ROS 2 work if it teaches ROS 1 exclusively. Do not delete historical material solely due to age if it is still conceptually important; label fit and compatibility.

## Quality checks

Run `python scripts/validate_catalog.py` and `python -m unittest discover -s tests -v`. No third-party course PDFs, scraped paywalled content, private messages, resumes or contact details. All contributions should use original paraphrases and credit source authors by link.

The existing 146-item inventory is a 2026 research snapshot, not a continuously monitored database. Annual audits are encouraged.
